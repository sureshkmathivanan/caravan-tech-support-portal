# User Personas

## 👨‍🔧 Technician (Primary User)

### Description:
A field technician or repairer who services caravans across Australia. Often works onsite with limited internet connectivity and minimal time for searching manuals.

### Goals:
- Quickly find parts and repair instructions for a caravan using the VIN
- Understand how to replace or repair specific parts
- Ask questions or troubleshoot via AI assistant

### Pain Points:
- No central repository of caravan part documentation
- Inconsistent naming/labeling across brands
- Paper manuals or ad hoc PDFs are hard to search
- Time wasted on phone support with manufacturers

### Tech Proficiency:
Moderate (mobile-savvy, familiar with service tools but not technical documentation)

---

## 🏭 Manufacturer Admin

### Description:
An employee from a caravan manufacturing company responsible for uploading and maintaining caravan data.

### Goals:
- Upload legacy caravan specs and parts data via templates
- Use the API to sync future data
- Ensure technicians always have access to the latest info

### Pain Points:
- Lack of standardized templates
- Manual effort required to clean historical data
- Risk of incorrect data entry

### Tech Proficiency:
Moderate to High (familiar with Excel/CSV, some API understanding)

---

## 👩‍💼 Platform Admin (You / Portal Owner)

### Description:
Internal owner of the platform (e.g. product manager or support lead)

### Goals:
- Manage user roles and permissions
- Monitor data quality across manufacturers
- Oversee AI assistant accuracy
- Support scaling up to multiple brands

### Pain Points:
- Ensuring consistency across manufacturers
- Dealing with incomplete or incorrect data
- Balancing usability with technical complexity

### Tech Proficiency:
High
