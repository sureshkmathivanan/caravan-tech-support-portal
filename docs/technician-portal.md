##Technician Portal Design & Flow

#Overview
The Technician Portal is a web-based interface designed to help technicians quickly search for caravan details using the VIN number and access important information such as parts and repair instructions.

#Key Sections:
VIN Search (Top Section)

Purpose: Allows technicians to input or scan a VIN to retrieve relevant caravan details.

Interaction:

Input field for VIN number.

Search button that triggers the query for caravan information.

Caravan Details (Middle Section)

Purpose: Displays detailed information about the caravan, including the model, year, VIN, and an image of the caravan.

Interaction:

Caravan image placeholder.

Caravan details displayed below the image (e.g., model name, year, VIN).

Parts List (Bottom Section)

Purpose: Displays a table of parts associated with the caravan, including part names, numbers, short descriptions, and clickable “View Repair Instructions” links.

Interaction:

A search bar to filter parts by name or number.

A table displaying the part name, part number, and description.

Each part includes a clickable link to view repair instructions.

#Flow
Technician enters a VIN number in the search bar and clicks "Search".

The system retrieves and displays the caravan details.

Technician can scroll through the list of parts.

Clicking on a part opens a detailed view (future feature for repair instructions).
